# 台詞・掛け合い執筆ガイド

DESIGN §8 の規範（説明しない・気持ちに名前をつけない・「だから/つまり」でつながない・主題を言わせない）の上に載る実践則。
すべての原則は「全角22字×2行の吹き出しを1個書く瞬間」に使える形にしてある。行区切りは `/` で示す。

## 1. 掛け合いの設計原則

- **1吹き出し1情報**。22字×2行に事実を2つ入れない。入らないなら情報を捨てるか、次の吹き出しに割ってラリーにする。
- **長さの上限**: 初回会話3〜5吹き出し・考察会話2〜5吹き出し・待機1吹き出し（content-briefs の3層構造）。5を超えたら必ずどれかを削る。
- **質疑応答で終わらせない**。答えのあとに一言足す（毒・余談・ボケ）。「ありがとう、おいしかったよ。カビが生えてたけどね」型。
- **話題転換は連想でつなぐ**。相手の台詞の中の一語を拾って次へ滑る（レコード→音→耳→寒い）。接続詞で論理をつながない。
- **ボケ=逸脱、ツッコミ=修正**。どうしても要る設定説明は「キリコの誤読→ガイドの修正」に偽装する。修正セリフだけが正しい情報を運ぶ。
  - キリコ「ここ、天国ンゴ？」→テト「待合室よ。……たぶん」
- **キリコは質問役**。ガイドに講義させない。ガイドが自分から語ってよいのは自分の不満・自慢・愚痴だけ（情報でなく欲求で話す）。
- **発火タイミング**はテイルズ式: 進行の節目（ノート取得後・レコード取得後・改札開通後）にフラグで開き、**話しかけたときだけ**再生。強制しない。
- **語尾・口癖は3回に1回**。毎吹き出しに付けると читない。動揺・照れの場面でだけ外す（ギャップが感情の信号になる）。
- **遮り・無言・話の飛びは技法**。「……」だけの吹き出しは1ラリーに1回まで使ってよい。むしろ一番怖い返事になる。

## 2. 怪異考察を自然に語らせる技法

- **断定は誰にもさせない**。知識キャラも「〜らしい」「〜って聞いた」「諸説あるアル」止まり。断定した瞬間 wiki になる。
- **情報源をキャラの人生に紐づける**。「常連さんが言うとった」「消えたスレで読んだ」「うちの婆ちゃんが」——出典が固有名詞化するほど伝聞は生々しい。
- **利害と感情に絡める**。規則を規則として言わせない。「夜に出歩けない」は、出歩きたいキャラの不満として言わせる。テトはレコードより「31年」の方が気になる。
- **疑問形・体感で閉じる**。「〜って本当かね？」「……気のせいアルか」。結論先行の説明順でなく感覚先行（「うまいんだな、これが」型）に語順を組み替える。
- **考察は外れていてよい**。むしろハズレ考察・くだらないオチの噂を混ぜる（夕闇通り探検隊方式）。全部が当たりの怪異はデータベース臭くなる。
- **複数ソースをわざと少し食い違わせる**（会話・貼り紙・ノート）。矛盾がプレイヤー側の考察を生む。整合を取りにいかない。
- **オチと正体は言わせない**。「……で、その先は聞いてない」「やめろや　この話」で会話ごと打ち切るのが一番後を引く。

## 3. 恐怖とギャグの切り替えリズム

- **怖い発見の直後に日常の一言**（実況スレの「やめろや」構造）。茶化しは恐怖を殺さない——聞き手の防御を一度解除して、次の一撃を通す呼吸。
- **切替には橋を架ける**。唐突な切替はテンポを壊す。
  - 恐怖→ギャグ: 生理反応（悪態・ため息・腹の音）を経由する。
  - ギャグ→恐怖: 「一人だけ笑っていない」「返事がない」「音が消える」を経由する。
- **ギャグの直後の静寂も武器**。ボケ→ツッコミ→（無音・bgm:null・返事なし）の三拍目が本命。
- 合いの手の型は3つ: (a)茶化し（草・嘘つけ）、(b)実務ツッコミ（写真撮れや・戻ろうや）、(c)沈黙か話題転換（＝一番怖い合図）。(c)は温存して要所だけ。

## 4. やってはいけないパターン集（ビフォー→アフター）

1. **場所を独り言で説明する**（テト）
   - ✗「ここは出口のない異空間で/バックルームと呼ばれてるの」
   - ○「出口？　……さあ。/探すのは　31年前にやめた」
   - 情報（出口がない）を本人の時間と諦めに変換する。地名は言わせない。
2. **ルールを教訓として説明する**（つくよみちゃん）
   - ✗「白い人と目を合わせると/連れていかれるので危険です」
   - ○「この村では、そう/することに　なっているんです」
   - 理由を言わない。「しきたり」として言うと、理由の欠如そのものが怖くなる。
3. **気持ちに名前をつける**（キリコ）
   - ✗「吾輩、こわいンゴ……/はやく帰りたいンゴ」
   - ○「……時計、まだ2時ンゴ。/……さっきも　2時だったンゴ」
   - 感情語を消し、感情の原因になった観察だけを言わせる。
4. **「つまり」でまとめる**（ロゼ）
   - ✗「つまり　住民は怪異に/さらわれたということアル」
   - ✗を直すなら ○「さらわれた、って聞いたアル。/……ま、諸説あるアルが」
   - 結論を伝聞に格下げし、留保で閉じる。ロゼなら更に短く「……諸説あるアル」だけでもよい。
5. **怪異を wiki 口調で解説する**（リノ）
   - ✗「牛の首というのは　聞くと/死ぬと言われる怖い話ですよ」
   - ○「牛の首？　ああ……/たのんだ人は　おらんねぇ」
   - 怪談の知識を「店のメニュー」の文脈に流し込む。中身は語らせない。

## 5. キャラ別の「逃げ方」

説明しそうになった時・オチを言いそうになった時に、キャラらしく会話を打ち切る／そらす定型。迷ったらこれで閉じる。

- **キリコ**: つぶやきで流す。「……気のせいンゴ」「……見なかったことに　するンゴ」。夢の中では口数少なめが正。
- **ロゼ**: 一言で切る。「……そうアル」「先に行くアル」。問い返されても黙る。沈黙もロゼの台詞。
- **テト**: 「べ、別に」で照れ隠しに転換→31年の時間ネタに滑って本題を捨てる。「べ、別に　あんたを待ってた/わけじゃないけど」
- **リノ**: 食べ物の話に置き換える。「……ま、出汁が冷めるでねぇ。/はい、おでん」。怪異よりも営業。
- **つくよみちゃん**: 祈りに置き換える。「わたしは　祈っておきますね」。誰のためかは言わない。
- **ネムリン**: 眠気に負ける。「それでね、うち……/……眠たいむ〜ん」。核心の直前で寝るのが役目。
- **おんちゃん**: あたたかさに置き換える。「まあ　お茶でも飲むおん。/ここは　あったかいおん」
- **にぃちぇ**: 曜日に戻る。「あ！今日　日曜日だニィ！」。深淵ネタは看板に任せ、本人は逃げ続ける。
- **ミャウミャウ**: 「ぷゆゆ🥺」で説明不能のまま消える。逃げ方＝退場。
- **レイ**: 定型放送文に戻る。あるいは文の途中で途切れる。「おかえりは――」
- **シヨ**: ツンデレ返しで突っぱねる。「か、勘違いすんな。/あたすは　通りすがりだ」。照れ・動揺の瞬間だけ津軽弁が一瞬漏れて（「〜っ、めぐせぇはんで/見んでけじゃ！」）余計に怒る。
- **八尺様・片足の老人・ムッジェ**: 逃げ方不要。言葉を持たないキャラに言葉を足さない。
