# 界隈曲スタイル補遺（docs/style-kaiwai.md）

「全てあなたの所為です。」「界隈曲」「ころんば」「ヤツメ穴」等の**様式だけ**を借りるための補遺。DESIGN §8（ジャンプスケア禁止・説明しない）の下位規範。
指針は界隈の言い回しを借りれば「本家を向くのではなく、本家と同じ方向を向く」。実在の曲・名義・画面は一切写さず、
構造（**無題・無名・断片・複製・沈黙**）だけを自前の素材で作り直す。怖さの正体は大音量ではなく「存在の不確かさ」。

## 1. 音 — MML（@onjmin/dtm）でできる界隈曲テク

- 提示順の原則: **懐かしさ→違和感**。まず地味で郷愁のあるループを聴かせ、2周目以降・後半で1点だけ狂わせる
- **土台**: 低いキックの四つ打ち（`#drum=` の basic/8beat、またはベーストラック o1〜o2 の c8r8 刻み）。BPM は 70〜100 の遅めか 140 超のどちらかで、中庸を避ける。ベースはルート弾きで地味に
- **和声**: マイナーキーに add9/11/aug を「1音だけ」混ぜる。正しい進行の1音を半音ずらすだけで界隈曲的な違和感が出る（deep1/deep2/deep4 の書法を土台に、1音だけ崩す）
- **ツインボーカル代用**: 同じ旋律を2トラックに重ね、片方の頭に短い休符（r32 等）を置いてにじませるか、1オクターブ下で重ねる。ところどころ片方だけ5度上に逃がすと「裏歌詞」感が出る
- **狂うオルゴール**: トイ質感の短い単旋律ループを作り、変奏版は `#edo=31` を宣言して `+`/`_`（約39セント）を1〜2音に付けた「壊れた再演」にする。音律は曲単位なので、狂った版は必ず**別 MML ファイル**に分ける
- **無音を楽器にする**: r1〜r2 の完全な休みを恐れず入れる。playMML の loop はシームレスなので、ループ終端の休符がそのまま「息継ぎ」になる。bgm: null のマップと SE（tick / hum / popo）だけの時間を最大の武器として扱う
- **隠しメッセージ**: 高音のパーカッシブなトラックに長短2種の音価でモールスを刻む（実際に解読可能な短語。内容は怖い言葉でなく優しい言葉に——kousatsu-bait 技法2「恐怖の裏の善意」と同系統）
- **スティンガー**: 発見・振り向きには16〜32分の下降アルペジオ1本のみ。突然の大音量は規範どおり禁止
- **ラウドネス**: 追加曲・変奏も bgm.ts 冒頭の手順で `#volume=` を測って -23 LUFS に揃える。ローファイ感は音色と書法で作り、音量差では作らない

## 2. 文字 — 無題・名無しの美学（表示バグに見えない範囲で）

- **無題は「枠」で見せる**: 空文字単体は不具合にしか見えない。かぎ括弧・一覧の行・名前欄という「枠」が残ることで初めて「題が無い」と読める——レコード名『　』（全角スペース1字）、看板「無題_037」、名前欄「　　氏」
- **記号タイトル**（「------」「______」等）は、実題を持つ項目と同じ一覧に並べて初めて効く。単独では使わない
- **ゼロ幅文字・制御文字は使わない**（DotGothic16 で豆腐化・validate 落ちの危険）。「読めないが意図はある」は全角スペース・ダッシュ・自作の文字化け風文字列（縺〜系の見た目を模した創作文字列）で代用する
- **名を言わないタブーは構造で作る**: 消えた投稿者を NPC 全員が別々の呼び方で呼ぶ／名前を尋ねると会話が打ち切られる。実在界隈の伏字作法（「××氏」等）をそのままなぞる表記は避ける
- 文字化け・縦読み等の暗号は1マップ1個まで。全部解けなくても筋が通る「余白」を残す（答え合わせ禁止は kousatsu-bait の運用指針に従う）

## 3. 追加要素の提案（コスト見積り付き）

1. **無題のレコード『　』**（コスト小: RecordDef 1件＋MML 変奏1本＋配置イベント1箇所）
   クリア後にのみ hub のベンチに置かれる5枚目。メニュー「レコード」の一覧では題が『　』1行だけ。再生すると title 曲の「壊れた再演」（#edo=31 でピッチの狂った変奏・朗読なし）。進行・ノート・実績に影響しない完全なおまけ
2. **名前のない作り手の痕跡**（コスト中: 看板3〜4枚＋既存NPC台詞数行、kakolog2）
   dat落ち棚の1つを「無題_037」「無題_041」だけが貼られた職人スレの遺構にする。過去ログ看板3枚で「饒舌→『宣伝せんといて』→沈黙」の変化を辿らせ、住民は「あの人」としか呼ばない。リノの考察会話に一言だけ足す。経歴・曲数・日付は実在の誰とも一致させない
3. **自販機のうなりモールス**（コスト小: sfx 1本の差し替えのみ）
   hub の壊れた自販機の `hum` を長短のあるループにする。解読すると「つりせん　とっといて」程度の生活の言葉（シヨの小銭ネタと接続）。字幕・ノートには載せず、テキストでの答え合わせもしない
4. **クレジットの空欄**（コスト小: scenes.ts のエンディング1行）
   クレジットに「さっきょく　　　　」の空欄行を1つ置く演出。ただし直後（または README）に実際の楽曲クレジットを漏れなく正記して、演出と権利表記を両立させる

## 4. 著作権・倫理の線引き

- **写さない（著作物・人格に属するもの）**: 実在曲のメロディ・歌詞・inst/UST（配布物も名無し転載への条件付き許諾でありゲーム流用は不可）、MV のドット絵・画面構成の複製やトレース、「ヤツメ穴」等の実在曲名、「ころんば」「x0o0x_」「全てあなたの所為です。」等の名義および「全て○○の所為です。」型のもじり名義、ニコニコの削除画面・YouTube 初期アイコン等の実在プラットフォーム UI、「教育文字」等の特定ロゴ表現
- **借りてよい（アイデア・様式・社会現象）**: 無題・記号タイトル・名無しの作者という命名慣習、ローファイ四つ打ち＋奇妙なコード＋平坦な合成声という音楽様式、黒背景・ドット絵・音ハメという映像文法、モールス・文字化け・縦読みという暗号ギミックの発想、失踪・削除・ミラーだけが残るというフラグメント・ロアの構造、供養スレ・伏字・なりすまし騒動という現象の型
- **実在の失踪者を再演しない**: 元ネタの作者は「自分の話をしてほしくない」と明言して消えた実在の人物。同定できる要素（実名・実ハンドル・実在の固有作品名・「4曲だけ残した」等の固有の事実関係・実際の年表の日付なぞり）はゲーム内に一切置かない。§3-2 の「作り手」も必ず架空の造形にずらす
- **実在界隈への言及ではなく、架空の同型文化の創作に徹する**: 板・職人・供養の作法はすべて「おんJ世界の架空文化」として自作する。界隈曲コミュニティに商業利用への忌避感があることを踏まえ、実在曲・実在素材を「入れない」ことを企画段階の決定として固定する
- ネット怪談そのもの（きさらぎ駅・八尺様等）は匿名の集団口承であり題材にしてよい。ただし特定作家による楽曲化・アートワークの具体表現はなぞらない。「本作はフィクションです」の明記（DESIGN §10）は本補遺由来の要素にも適用する
