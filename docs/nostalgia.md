## 0. 位置づけ

- この文書は DESIGN.md §4「時間帯システム」と docs/style-everyday.md（日常スタイル）の下位仕様にあたる。
  下限品質は docs/content-briefs.md の品質ノルマ、台詞は docs/dialogue-guide.md、空間は docs/style-spaces.md、

  そのまま取り込まない。ネットの評論・分析を読んだうえで、別の形で追体験できるように取り入れる。方向性はノスタルジック。
- 作者の確定方針（この文書の全項目がこれに従う。例外なし）
  - 日常が本体、怪異は脇道のおまけ。ノスタルジー層で怪異を増やさない
  - 夕方の怪異はゼロ。深夜のNPCは0体（気配はよいが、人は出さない）

  - おんJらしいボケとツッコミの軽さを保つ。実在の作り手を特定できる描写は入れない
- 本仕様は3案（chikuon＝蓄音の盤／structure＝ふたつの夜の時間割／content＝紙の下の紙）と3人の審査（研究・作者・実装）を統合したもの。

## 1. 調査の結論：深夜徘徊とノスタルジーはなぜ効くのか

### 1.1 懐かしさは「古い物」ではなく「構造」から生まれる

### 1.3 Xのノスタルジック流行が効く理由と限界

- 平成レトロ・AI の昭和画像・リミナルスペースが共感を集めるのは、過去を見せているからではない。
  懐かしさが起きる条件（反復・不在・帰れなさ）を記号で刺激しているからである。
  Havlena & Holak の対人的・仮想経験ノスタルジア（廣瀬の整理 [確認済]）に加え、座談会の没場所性の議論がある
  （https://note.com/hummm09/n/na3c6a6da35f5 [確認済]）。
- 限界は三つある。
  - AI 画像は平均化されて「誰の記憶にも根付かない」ものになる（AFP/NZ Herald [未検証]）。
  - 「全員これ持ってた」型のあるあるは、世代差や体験格差で外れる人を疎外する（ヒオカ、mi-mollet [未検証]）。
  - 定番記号の羅列は、作品が「エモいっしょ」と言っている状態になる（リトルマッチョ、note [未検証]）。
- 高野光平は、定番の話題そのものより「となり」にある地味な物の手触りを見るよう勧めている（プレジデントオンライン [未検証]）。
  https://president.jp/articles/-/76668?page=2
- 「現実で散歩すればいいのでは」問題について、綾部和は現代を舞台にしない理由として「現代なら、リアルに外で遊べばいい」と語っている
  （東スポWEB 2ページ目 [一部誇張あり。この発言部分は原文で確認済み] https://www.tokyo-sports.co.jp/articles/-/274648?page=2 ）。
  本作はこの問いに、ゲームにしかない時間構造で答える（§2）。
- 一日の固定と絵日記については、綾部の「ちょっと足らない」という発言がある（4Gamer [確認済] https://www.4gamer.net/games/685/G068503/20230627031/ ）。
  身近な冒険については、Real Sound の綾部インタビュー [一部誇張あり。「家の壁や商店街の屋根」の発言部分は原文で確認済み] を参照した。

## 2. 翻訳の原理

### 2.1 核：借り物の過去ではなく、ゲーム内の一日で過去を作る

1. **反復→空白→再会**: 夕方に同じ音・人・紙に2回以上触れさせる。宵にそれが減っていく途中を見せる。深夜は全部抜き、朝に一つずつ返す。
   プレイヤー自身が数時間前に見た町が、懐かしさの材料になる。
2. **ふたつの夜**: 宵（yoru）は「時間が流れる夜」、深夜（shinya）は「時間が止まった夜」にする。
   他者の気配は宵に集める。深夜には人を出さず、光の島・身体・座る余白だけを置く。
   夕方の7人から深夜の0人へ段差なしに落ちると、深夜はホラー側にしか振れない。宵がその段差を埋める。
3. **止まった夜を、手の中の物で測る**: 時計がすべて2:00で止まっていても、缶は冷めていく。
   現実の散歩では手に入らない、ゲームにしかない時間構造にする（「現実で散歩すればいい」への答え）。
4. **「さっき」が「きのう」になる**: 日付をまたいだあと、同じ一行は黙って「ゆうべ」の一行になる。
   表示を変えるだけで、キリコは何も言わない（chikuon から接ぎ木）。
5. **痕跡は置くだけ、郷愁の隣には体を置く**: 残像も回想も「だれもいない」も書かない。
   懐かしさの隣には、蚊・冷え・眠気・会釈の気まずさのどれか一つを置く（エモ＝複合感情）。
6. **夜の本音は朝に褪せる**: X の「エモい夜」投稿のような深夜のポエムは、朝のキリコが自分で消す。
   流行を説教で批判するのではなく、自虐のツッコミで相対化する。
7. **象徴より時間の層**: 昭和・平成の記号は足さない。貼り紙の下の貼り紙、来なかった未来の点線、ポケットの紙切れ（高野の「となり」）で出す。

## 3. 採用する機能

- 優先度: **P0 = 今回すぐ実装（エンジン変更なし）**／P1 = 次の実装（最小のエンジン変更を含む）／P2 = 作者判断で保留。
- 共通の新ファイル: `src/data/nostalgia.ts`（データ層のヘルパー。エンジンではない）。中身は次のとおり。
  - `OUTDOOR_DAILY = ["street","sumire","kawara","danchi","kokudo","ekimae"]`
  - `yoruStep(s)`: 6地区の `done:<map>:arrive_yoru` の数（0〜6）。往復しても増えない（lights.when 用に GameState 版の `yoruStepSt(st)` も置く）
  - `yoruClock(s, off=0)`: `20:${5 + 7*yoruStep + off}`（20:05〜20:47）
  - `chukeiDan(s)` / `kanLv(s)` / `kanTick(s)` / `kanLine(s)` / `kanShinya(s)` / `nikkiKey(s)` / `NIKKI` / `nikkiSummary(s)`
  - validate は全フラグを true にして走るので、数値・文字列のフラグは必ず `typeof` で読む
    （例: `kanLv = typeof v === "number" ? v : v ? 1 : 0`）
- フラグはすべて `seen_` / `got_` 接頭辞（FLAG_OK に収まる）。Story に新しいメソッドは足さない（makeStory のスタブは不要）。
- `s.note()` はノスタルジー層で**一度も呼ばない**。新しいスプライト・チップ・BGM は使わない。SE は名簿にある名前だけ使う。
- P0 の実装順: §6 のバグ修正 → `nostalgia.ts` → P0-1（宵の土台）→ P0-2・P0-3・P0-4（夜の自室）→ P0-5・P0-6・P0-7（深夜）→ P0-8・P0-9・P0-10（夕方の仕込み）→ P0-11（朝）。
  1機能ごとに `pnpm validate`（0 errors / 0 warnings）と `pnpm lint` を通す。

### P0-1 宵の町：yoru の穴をふさぐ（M）

- **体験**: 晩ごはんのあと外へ出ると、夕方とも深夜とも違う宵の口の町がある。
  時計塔は 20 時台で、地区を回るたびに数分ずつ進む。街灯はいつのまにか点いている。コンビニのレジには店員の背中が見える。
  窓からは風呂のにおいとナイターの実況が届く。4地区目あたりでキリコがあくびをし、寝に帰る流れになる。
- **根拠**: style-everyday §2 の時間帯5要素（光・音・在不在・開閉・時計）。nightwalk A・C。
  Diel & Lewis（公共の場に人の気配があると不気味さが下がる。深夜の不在の前段になる）。codebase-map の「yoru は夕方の文言に落ちる」バグ。
- **実装**（エンジン変更なし。宵の NPC は P0 では0体）
  - 屋外6地区＋apart に `arrive_yoru`（auto・once・`when: tod==="yoru"`・座標は既存 arrive と同じく y0 の空き）を足す。本文は1〜2行。
    `yoruStep(s) >= 4` かつ `!seen_akubi` なら、あくびを1行足して `seen_akubi` を立てる。
  - yoru の既定分岐が夕方の文言に落ちている箇所へ、`t === "yoru"` の分岐を足す:
    - street: 時計塔 clock_tower(13,12)（`yoruClock`）、街灯 lamp_ev(11,12)、とこや barber(24,9)（時計は見せない）、

      自販機 vending_ev(19,12)（赤い札 → P0-6 の前振り）、すずき家の窓 h1_win(6,18)、たなか家の戸 h2_door(16,18)

## 7. 不採用とその理由

- **蓄音の録音システム一式**（chikuon の「きょうの盤」3本のみぞ、`hear` の約25か所への配線、メニュー内の録る／かさねて録る）:
  - 録音条件（同じマップ・30秒以内・2回）が不透明で、拒否文（「まだ耳になじんでない」）が規則の説明になる
  - 操作は「歩く＋調べる」だけという原則からはみ出す
  - `keepInto` がメニューからしか呼ばれず、validate の対象外になる。会話中も playMs が進むので、30秒の窓が切れる
  - 反復は、布団で聞く町（P0-3）とはがきの動線（P1-7）で作る。「きのう」への呼び替えだけ日記に接ぎ木した
- **2時の半速・1オクターブ下の再生／『　』（2時は盤に乗らない）／自室だけ原速／缶で盤をあたためる**:
  - 説明されない新しい規則で、ノスタルジー層に怪異を足すことになる（深夜の違和感が4系統目になる）
  - 減速再生はスロー再生の怪談の定番で、slowed+reverb というエモ加工の直輸入でもある
  - 技術面では、`train`・`densha_far` の o1 が o0 に落ちてほぼ聞こえなくなる
- **もとの場所でかける（二重露光）・朝の「きかせる」（盤が前提）・スレにあげる**:
  - 無人の同じ場所で夕方の音を鳴らすのは、音で残像を描くことになる（德山・中村の罠）
  - 隣人の声を掲示板に上げるのは、親音ハハを不採用にした基準（DESIGN §5）と倫理面で衝突する
  - 朝に声の持ち主と会う体験は、盤なしの P1-3 に移した
- **クリア後のタイトルでの残響**: 鳴らす盤が無い。タイトルには 17:03→7:00 の差分がすでにある。
- **国道のまんなかをわたる**:
  - 危険行為の手本になる。地図上ガードレールに切れ目が無い
  - hodokyo 怪異の「国道は歩道橋でしか渡れない、車は来ない」という前提を崩す
- **迎えの車（声とドアの音だけ）・深夜に一つだけ灯る他人の窓・夜勤の店員・新聞配達**: 見えないものの声、深夜の人の気配は、新しい怪異として読まれる。深夜のNPC 0体・窓ゼロの基準線を壊す。
- **深夜の遠い電車・トラックの音、東の空が一か所だけ白む**:
  - 深夜2時の電車の音は囲い（駅）の予兆 `seen_densha2` の文法と衝突する
  - 2:00 で止まった夜に時間の進む場所を置くと、新しい違和感になる。時間は缶で測る（P0-6）
- **白む帰り道（terminus→朝の暗転の色の変化）**: 作者が書いたエンディング直前の流れに手を入れる。fadeOut の transition を全体で変えるのは、見返りに対して影響範囲が大きい。
- **朝の机のあき缶**: 「深夜の町は夢か現実か」という考察の軸に答えを出してしまう。
- **宵の消灯を文章で書く（「むかいの家のあかりが、さっきよりすくない」）・「タクシーのりば、からっぽ」**: 不在の名指しで、痕跡ではなくなる。消灯は P1-1 で光だけにする。
- **マップ往復ごとに増える宵のカウンター（`seen_yoru_step`）**: ワープの往復だけで段が上限に達する。地区到着の once（`yoruStep`）で代用した。

- **キリコに「いい音ンゴ」と感想を言わせる、ラベルに感情語を書く**: 気持ちの名指しにあたる。
