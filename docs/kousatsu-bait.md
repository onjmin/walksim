## 2. 考察を最も誘発する曖昧化装置（効果順)

1. **無題・無名**（曲名なし・チャンネル名なし）: 呼び名の発明を強制する（「4番目の動画」「きさらぎ駅のやつ」）。言及するだけで考察になり、たまに付くタイトルが事件になる。
2. **解ける小さな暗号**（モールス・字幕トリック・逆再生）: 「解けた」報告が最上位に来る。**解読結果が優しい言葉**（ありがとう系）だと最も愛される——恐怖の裏の善意という落差。
3. **数**（13段目・8×8=64・今何段目？）: 数えられるものは必ず数えられる。歌詞と映像の数の一致は「鳥肌」報告の定番。
4. **意味の通らない歌詞＋一箇所だけ通る空耳**: 聞こえ方の個人差が合意形成ゲームになる。全文書き起こしが貢献行為になる。
5. **削除・非公開・リンク切れ**: 喪失がアーカイブ探索と伝承を生む。「消えるかもしれない」が再訪の動機になる。
6. **作品間の目配せ**（対曲リンク・1ドットの引用・模倣曲300）: 同定表・年表・対応表づくりという「作業系考察」を生む。
7. **周期的な儀式**（周年・年1プレミア）: 巡礼コメント「戻ってきた」「おすすめに呼ばれた」の共同体感覚。
8. **作者の沈黙**: 概要欄に説明が無い・ピン留めがリンク1行——説明の欠如が最大の発話権をファンに委譲する。

## 3. 感情のレジスター

怖い（ゾワゾワ）・切ない/エモい・懐かしい・おかしい（カルトジョーク）・感謝が**同居**する。純粋な悲鳴は少数派で、主流は「怖い発見→好き」「ゾワゾワして楽しい」という変換。最も強い接着剤は**喪失への切なさ**（削除された原曲、消えた投稿者、「おかえり」「ただいま」文化）。恐怖の直後に日常の軽口を置く往復運動はコメント欄自体がすでにやっている——本作の規範8.5（怖い発見の直後に日常の一言）はこの文化の再現として正しい。

## 4. 本作『蓄音キリコと きさらぎ回線』への考察バイト技法 10選
（技法のみ借用。特定の歌詞・記号・キャラクターは使わない）

1. **段数が合わない階段**（kakolog2 の地層を降りる階段、または hub→kakolog2 の下り口）: 下りは13段、上りは12段。リノは会話で「12段」と言う。ノート・テキストでは一切触れず、タイルとSE（足音の回数）だけで実装。数えた者だけが矛盾に気づく。
2. **解読すると優しい環境暗号**（kisaragi）: 駅名標の隣の信号灯が長短の点滅を繰り返す。モールス等で解読すると怖い言葉ではなく「みつけてくれて ありがとう」系の一文。.espect 型の「恐怖の裏の善意」。validate 対象外の点滅パターン＋クレジット画面に規則のヒントを1行だけ。
3. **同じ日付が3箇所、1箇所だけズレる**: room のカレンダー・kura の日記断片・kakolog2 のdat落ちスレタイに「2021/03/15」。ただし1箇所だけ「03/16(火)」。誰も言及しない。実際の曜日計算と合わせておく（検証勢が曜日を調べる）。
4. **名前の無い存在の呼び名がNPCごとに違う**: 八尺様（名前欄「？？？」）を、つくよみちゃんは「白いワンピースの方」、リノは「背の高いお客さん」、ネムリンは「ぽぽぽの人ピロ」と呼ぶ。同一存在だと明言しない——「呼び名の発明」をプレイヤー側に起こさせる。
5. **二度目に来ると1文字違う張り紙**（yellow）: 規範8の「二度目に来ると少し違う張り紙」を強化——変化は1文字だけ（例:「出口」→「出ロ」）。スクショ比較したくなる粒度にし、確かめる手段（再読で戻る等）は与えない。
6. **NPCの数字が食い違う**: テトの「31年ここにいる気がする」に対し、リノが「あの黄色い部屋の子？ 去年ふらっと来たきりよ」と言う。どちらも嘘にしない（夢の時間は伸び縮みする）。考察会話（8.5）の1回きり掛け合いに埋める。
7. **アナウンスの空耳**（train / kisaragi）: 足立レイのTTSアナウンスの末尾に、音量を落とし右にパンした一語を重ねる（Story.se の pan 活用）。聞こえたか自信が持てない音量に調整し、字幕・ノートには載せない。
8. **鏡写しのレコード**（rec_a と rec_c）: 文面を対句構造にする——片方が「風呂入ってくるわ」なら片方は「ただいま、いい湯やった」。終点の一斉再生で並ぶと初めて対に気づく。冥路の「Other one」方式＝説明せずに対だけ置く。
9. **UIの外側に1つだけ手掛かり**: メニュー「ノート」の未発見「？？？」の hint 薄字、またはクレジット画面の1行に、本編で語られない固有名（レコードの元の持ち主のコテハン等）を1つだけ置く。「字幕ONで判明」型の、UI探索への報酬。
10. **消えた原典の断片**（kakolog2 ＋ village）: dat落ち棚の1つだけ「このスレは削除されました」の表示にし、そのスレの内容の断片（1レスの引用風の一文）を village の蔵の看板に残す。原典が消えて断片だけ漂着している「= [Remix]」構図。ミャウミャウの3形態（A/B/C）も同種の装置として機能する（毎回姿が違う＝同定考察の的）ので、目撃①②の姿の差分に小さな共通点（同じ紙袋の皺など）を1つ仕込むとよい。

**運用上の示唆**: (a) 考察の「答え合わせ」は絶対にしない——エヌ6年目でも新説が出続けるのは正解発表が無いから。(b) 優しい暗号(2)と怖い矛盾(1,3,6)を混ぜ、解いた者への報酬の感情を散らす。(c) エンディング後にタイトル画面へ小さな差分を1つ置くと「周回して確かめる」動機（周年巡礼の代替）になる。
