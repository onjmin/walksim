# コンテンツ制作ブリーフ（ワールド別詳細仕様）

DESIGN.md の下位仕様。各ワールドの担当者（エージェント）は自分のファイル**だけ**を書き換えること。
共有ファイル（data/index.ts・hub.ts・cast.ts・sfx.ts 等）には触れない。
自分のマップへの「入口座標」が変わる場合は、レポートに `inbound: <map> (x,y,dir)` と書く（統合時に hub 側を直す）。

## 共通規約

- セリフ 全角22字×2行まで。DESIGN §8 の執筆規範厳守（説明しない・気持ちに名前をつけない・ジャンプスケア禁止・死なない）
- 選択肢は安価風「＞＞1 〜」を使ってよい
- タイル: `src/data/tiles.ts` のパレットから組む（rpg の maps/*.ts の使い方を参考に読む）。暗さ・色は MapDef の `tint` / `dark` / `ambient` で作る
- 効果音は下の「SE名簿」にある名前**だけ**使う（実装は音響担当）。BGM は bgm.ts にある曲名だけ
- キャラ口調（cast コメントも参照）:
- **掛け合い・考察会話**: DESIGN §8.5 と docs/dialogue-guide.md に従う。各世界のガイドには
  (1) 初回会話、(2) その世界の主要ノート取得後の考察会話（once・2〜5吹き出し）、(3) それ以外の待機セリフ、の3層を書く
- **かいいノート**: 怪異・小ネタの発見時に `s.note("<id>")` を呼ぶ（DESIGN §6.5 の id 一覧）。
  発見の「瞬間」に呼ぶ（看板を調べた直後・目撃イベントの直後）
- **考察バイト**（docs/kousatsu-bait.md の技法10選。担当割り当て・すべて説明禁止＝テキストで答え合わせしない）:
  - yellow: 技法5「二度目に来ると1文字違う張り紙」（例:「出口」→「出ロ」。once フラグで2回目から差し替え）
  - village/kura: 技法3の一部「kura の日記断片に 2021/03/15 の日付」＋技法10「削除スレの断片が蔵の看板に漂着」
    （固定文言:「――たのしかったなあ、また/やりたいなあ、ばんめし　なんやろ」を蔵の看板の1つに）
  - kakolog2: 技法1「下り13段・上り12段の階段」（タイル+SE足音の回数のみ。リノが会話で「12段」と言う）
    ＋技法3の一部「dat落ちスレタイの1つに 2021/03/16(火)」＋技法10「削除スレ表示（鮫島事件の看板を流用可）」
  - kisaragi線: 技法2「信号灯の点滅を調べると長短パターンが読める→解読すると『みつけてくれて　ありがとう』系」
    ＋技法7「アナウンス末尾に右パン・小音量の一語」（se の pan 使用・字幕なし）
  - 横断（各担当のセリフ内）: 技法4「八尺様の呼び名がNPCごとに違う」（つくよみ=「白いワンピースの方」、
    リノ=「背の高いお客さん」、ネムリン=「ぽぽぽの人ピロ」）＋技法6「テト『31年』vs リノ『去年ふらっと来た』」
  - 統合担当: 技法3の room カレンダー・技法8「rec_a と rec_c を対句に」・技法9「ノートの hint 薄字に1つだけ固有名」・
    クリア後のタイトル画面に小さな差分1つ
- キャラ口調:
  - キリコ: 一人称「吾輩」、語尾「ンゴ」。夢の中では口数少なめ・つぶやき調
  - ネムリン: 一人称「うち」、語尾「ピロ」、口癖「眠たいむ〜ん」。虚弱・ふわふわ
  - ミャウミャウ: 語尾「ぷ」、「ぷゆゆ🥺」、自称おんJの侵略者。かわいいが説明不能
  - つくよみちゃん: ていねいで優しい「〜ですよ」「〜くださいね」
  - おんちゃん: 語尾「〜おん」。一人称は不安定（私/僕/おんちゃん）。あたたかい
  - にぃちぇ: 語尾「ニィ」。「あ！今日　日曜日だニィ！」。深淵ネタ
  - ムッジェ: 「ホゲェ……」のみ
  - ロゼ: 語尾「アル」。クールな常識人・口数少ない。束音ロゼの実史（企画スレ壊滅・遺構だけ残った）を本人は知っている
  - テト: ツンデレの型「べ、別に」。31歳（設定）・「31年ここにいる気がする」等の時間感覚ネタ。声あり(teto)
  - リノ: 45歳・伊勢出身・食堂の女将。生活の言葉で話す（おでん・出汁・営業時間）。客の噂話として怪異を語る。声あり(rino)
  - シヨ: ぶっきらぼうな一言ネタ（「息くせーぞジジイ」系）。深入りしない。声あり(shiyo)。※調査結果が届き次第・口調確定
  - レイ（アナウンス）: 機械的な駅放送文体。「〜です」「〜ください」
  - 八尺様: セリフは「ぽ　ぽ　ぽ」のみ（名前欄「？？？」）
  - 片足の老人: 無言

## SE名簿（音響担当が data/sfx.ts に実装。他の担当は名前を使うだけ）

既存（rpg由来・そのまま使える）: door, stairs, warp, item, save など sfx.ts に残っているもの。
新規（MML でも RPGEN でも可）:
- `taiko` … 遠くの和太鼓一打（低く・小さく）
- `suzu` … 鈴の音（シャン、と一振り）
- `rec_noise` … レコードの回転ノイズ（プチ、パチ）
- `rec_stop` … 針が上がる音
- `tick` … 時計の秒針一打
- `hum` … 蛍光灯のうなり（短いループ用ワンショット）
- `popo` … 「ぽ」一打（低い男声風の短い音。TTS は使わない）
- `kane` … 神社の鈴・鐘
- `train` … 電車の走行音ワンショット
- `mokyu` … 小さくかわいい鳴き声（ミニワイ用・任意）

  「（´・ω・｀）もともと　ここに　住民なんて/いなかったんだよ」等、2〜3言。名前欄「原住民」
- **ガイド: 重音テト**（声 teto・立ち絵 portraits/teto.png）: 唯一の事務椅子に座っている「先客」。

## world: village + kura（夕暮れの村・蔵 / 八尺様）

- village 26×20 目安。田・あぜ道・電柱・数軒の家（入れない）・神社・北端に蔵。tint 夕焼け（例 rgba(150,60,50,0.25)）、BGM sad

  白いワンピースの背の高いひとを見ても、目を合わせない・呼ばれても返事をしない・まっすぐ歩く。
  そのあと お守り（omamori）をくれる。`kane` を鳴らす。**ルールを「教訓」でなく「うちのしきたり」として言う**
  （説明口調禁止。「この村では、そう　することに/なっているんです」型）。
  2回目以降は短い気づかいの言葉（「日が沈みきる前に、帰ってくださいね」等）。
  考察会話（`note_hasshaku` と `note_jizo` 取得後）: 地蔵を直そうとした「誰か」の話。

- **八尺様**: 遠景に2〜3箇所、when フラグで出現制御（例: 神社に行く前は田の向こう（画面端）、お守り取得後は電柱の陰に移動している）。

  踏むと `popo` が数回（左右パンで方向を出す）＋画面がわずかに暗く（flash 黒 or fadeOut/In）→ 一歩後ろへ戻される（s.move）。死なない

- **kura（蔵のなか）** 10×8、dark 0.7、BGM null。古い木箱・帳面。看板×3（古い日記の断片。
  戦時の史料ではなく「蔵を整理した誰かの覚え書き」程度に留め、敬意あるトーン）。
  最奥に **レコードB（rec_b）**
- 帰路: お守りを持って hub へ戻るとき、入口付近で一度だけ `popo` が遠くに鳴る（もう近づいてこない）
