# 空間スタイルガイド — 界隈曲MVの視覚言語をマップに翻訳する

界隈曲4作（🔷 / エヌ / = [Remix] / .espect）のMV・サムネイル分析から蒸留した、本作の核
「ドット絵の不思議な空間を探索できること」の作り方。考察誘発の技法は docs/kousatsu-bait.md、
各マップの中身は docs/content-briefs.md を参照。**全て既存タイル（rpg-reze/rpgen の data/tiles.ts
パレット）＋ tint / dark / ambient / outside で実現する。v1 で新規チップは描かない**（末尾の発注メモ参照）。

## 1. 空間の文法 — 「暗闇の中の小さな灯り」

サムネ20枚超に共通する原理は「画面の9割が黒の虚無、被写体は中央にぽつん」。タイルマップへの直訳:

- **黒の海に床を浮かべる**: rows の外周・隙間に `" "`（outside の黒）を厚く取る。26×20 の部屋でも
  歩ける床は全マスの半分以下が目安。床の輪郭そのものが演出——長方形に敷き詰めず、くびれ・離れ小島を作る。
- **遭遇密度は低いほど界隈曲的**: 1画面（短辺約11マス）に「主役」は1つまで。ランドマークの間には
  何も置かない歩行区間を最低1画面ぶん挟む。空白は恐怖の主成分であって未実装ではない。
- **祭壇的シンメトリー**: 見せ場だけ左右対称に組む（対の街灯 `L`・対の木・対のベンチ、中央に扉/台/改札）。
  対称＝人工的な夢＝異界の濃い場所、日常区間は非対称——このルールを全マップで一貫させる。
- **あり得ない隣接（箱の中の箱）**: パレットは `{ ...TOWN, X: INDOOR["."] }` 式に1マップ内で混ぜてよい。
  黒の中に屋内の一室だけが浮かぶ・1マス幅の床が黒を渡る「一本道」は rows でそのまま書ける:

      "        #####      "
      "        H.Q.H      "   ← 黒（" "）の海に浮かぶ一室。
      "....D...#...#      "     床を1マス幅で延ばせば「一本の白い道」
- **黒は3種類**: 純黒 `#000`（きさらぎ線）・炭色 `#08070c`（hub）・色みの墨（kakolog2 `#050408`、
  yellow `#141005`）。outside の色だけで空間の温度が変わる。マップ間で使い分けを崩さない。
- **光と天候は既存プリミティブで**: dark＝サムネの強ビネット（中央だけ明るく四隅は黒）の直訳。
  tint＝「色あせた昼」（夕焼け・黄ばみ）。ambient: static＝画面ノイズ、dust＝浮遊粒子。
  局所光は「明るい色の床タイルを数マスだけ敷く」で表す（おんちゃんの部屋方式。光源チップは不要）。

## 3. 小物の記号学 — ジャンル慣習として借りる記号と置き場所

いずれも「置くだけ」。調べたときの一言はあっても、意味は書かない。

- **窓**（TOWN `W`/`w`）: 入れない家にも窓を1つ。誰もいないのに窓がある＝見られている感。village の民家、yellow の壁に。
- **開かない扉**: `D` を置いて warp を置かない。「どこにも　つながっていない気がする。」1ワールド1枚まで。
- **水**: マップ南端に `~` を1〜2行。サムネ下端の青い波形の直訳。village の用水路、kakolog2 最深部の水たまり。
- **参道の記号**: 井戸 `U`・石灯籠 `PROPS.stoneLantern`・墓標 `PROPS.grave`。village（神社まわり）に集約し他所では使わない。
- **白い幾何学記号**: `PROPS.magicCircle`（白い魔法陣）を床に1つ。白ドット・二重白枠の代用。説明ゼロで置くほど効く。
- **システムUI擬態**: `PROPS.monitorBars`（カラーバー）・`boardBroken`・`notice`。読める看板と読めない看板
  （■■■■伏字・かすれ）を混在させる。「読めない」も情報のうち。
- **対の物**: 街灯 `L`×2・ベンチ `B b`×2 を左右対称に。§1 の祭壇スポット専用。
- **隠しメッセージ**: 暗号（モールス等）の文言は必ず自作し、SEの明滅・鳴りのパターンや看板に仕込む。解いた人への
  報酬は「見つけてくれてありがとう」型の一言（ミニワイ方式）。攻略に必須の情報は絶対に入れない。

## 4. やってはいけない

- **MVの固有物の複製**: 琴葉姉妹・イワシテト・マグロ4号等のキャラ、クリックゲーム画面など特定MV場面の再現、
  ドット絵スプライトのトレース・改変流用。借りてよいのはジャンル慣習（無人駅・踏切・雨・黒の余白）まで。
- **固有名の使用**: 「全てあなたの所為です。」等の定型文・曲名・作者名を看板やセリフに書かない。
  ころんば本人を想起させる言及・パロディは界隈のタブー（リスペクトは空気で示し、名指ししない）。
- **過密**: 空白を埋めたくなったら物を消す。1画面に主役1つ・アクセント色2個・看板2枚が上限。
  「寂しいから何か置く」は本作では常に誤り。
- **記号の説明**: 魔法陣が何か、なぜ窓が灯るのかをテキストで語らない（DESIGN §8）。かいいノートの考察も
  伝聞・非断定のまま。対称・余白・色の意味をキャラに解説させない。
