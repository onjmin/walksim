# 日常スタイルガイド — 夕方の町・時間帯変化・朝の再訪（プロローグの一日）

DESIGN.md §4「時間帯システム」（street(夕)→room(夜)→深夜2:00→street(深夜)→駅→hub、エンディングは朝）の下位仕様。
有識者のネット調査（開発者インタビュー・GDC/CEDEC講演・批評）を本作の道具立て（タイル・tint・SE pan・全角22字×2行）向けに蒸留した。
下限品質は docs/content-briefs.md の品質ノルマ、視覚言語は docs/style-spaces.md に従う。
ただし夕方の街路は「黒の余白」より「生活の密度」を優先する例外区間（余白の美学は深夜側にとっておく）。

## 0. 原理 — 日常は基準線（ベースライン）である

怪異は絶対値でなく差分で知覚される。まず「正常」を学習させ、正常側からノイズを除去しておく。
8番出口は異変ゼロの学習区間を明示的に設計し、日常側の描画品質を「怖さの演出」でなく「誤検出防止」のために上げた
（ https://gamemakers.jp/article/2024_02_14_60602/ ）。
夕方の町はホラー演出ゼロで作る（DESIGN §4 の作者指示どおり）。深夜の恐怖の総量は、夕方をどれだけ本気で作ったかで決まる。

## 1. 夕方の町の設計則 — 10分の純日常を持たせる

- **お使いの連鎖で牽引する**: 大目標1つ（晩ごはんを買って帰る等）＋道中の小目標2〜3（ポスト・犬・自販機）。
  買い物・散歩など「生活の手続き」が探索の口実になる（夕闇通り探検隊 https://dengekionline.com/elem/000/000/920/920673/ ）。
  帰宅ドア＝夕方の終了なので「もう帰る？」の確認を一度だけ挟む（時間を送る操作に必ず意味を持たせる。ぼくなつ/P3の定石）。
- **発見密度が滞在時間を買う**: 無風区間の許容は分数でなく「毎分なにか見つかるか」で決まる（Chmielarz/コタケ/Bycer の共通見解
  https://www.theastronauts.com/2015/03/when-two-game-designers-argue-about-silent-hill/ ）。品質ノルマの10歩ルールを夕方は最優先で守る。
- **紙物のアーカイブ主義**: チラシ・貼り紙・掲示板・回覧板は全てに背景を持たせ、「なんとなく置いたもの」をゼロにする
  （SIREN「すべてのアイテムに背景がある」 https://news.denfaminicogamer.jp/interview/230802a ）。読める/読めない看板の混在は style-spaces §3 のまま。
- **NPCはくだらない雑談だけ話す**: 晩ごはん・やきう・宿題・恋バナ。説明・世界観・伏線口調は厳禁。日常会話こそ作品の体積であり、削ると痩せる
  （トワイライトシンドローム https://www.famitsu.com/article/202603/66912 ／学怖・飯島 https://www.4gamer.net/games/607/G060723/20240926043/ ）。
  うち1体は「追える生活」を持つ（マップを周回する犬の散歩の人。ムジュラ=少数NPCの観察できるルーチン https://realsound.jp/tech/2021/01/post-688154.html ）。
  うち1体は話しかけても会釈しか返さない通行人（8番出口のおじさん式。無害な他者が最良のベースラインで、深夜の「不在」の効きを最大化する）。
- **生活音SEが骨格**: ヒグラシ＋17時チャイム＋金色の光は「夏の夕方」想起の定番3点セット（ https://www.inside-games.jp/article/2026/07/25/185142.html ）。
  BGMは薄く、環境音主体が実在感を作る（ぼくなつ https://realsound.jp/tech/2023/10/post-1450690.html ）。ほかに遠い電車・踏切・店のドアベル・子どもの声（s.se の pan で距離を出す）。
  **音は全て正常の側に置く**（8番出口は異変チャネルを視覚に固定した）。ここで確立した定時音（チャイム・電車）が §3 の反転資源になる。
- **伏線は日常のふりをさせる**: 「不穏の種」は夕方の時点では完全に日常として読めるもの（工事のお知らせ掲示・子どもの噂のひとこと・夜スレの1レス）。
  背景情報による事前汚染は異変より安く、密度を上げても日常感を壊さない（Gone Home https://www.shacknews.com/article/75785/interview-gone-home-focuses-on-player-vulnerability
  ／株式会社闇・小中千昭「ホラーは段取り」 https://note.com/death_co_jp/n/ncce0d376e0c6 ）。
- **操作は歩く＋調べるのみ**: チュートリアルを詰め込まない。単純な操作系が想像力（パラノイア）の余地を残す
  （Frictional/Grip https://frictionalgames.com/2019-10-9-years-9-lessons-on-horror/ ）。急かさない・死なせない（ぼくなつ「負けない世界」 https://www.oricon.co.jp/special/56926/ ）。

## 2. 時間帯変化の最小構成 — 夕→深夜→朝を最安で売る

調査の結論: **光と色／環境音／NPCの在・不在／店の開閉／定時音と時計**の5点で成立する。中でも「不在」が最も安い時間表現
（時間システム総論 https://automaton-media.com/articles/columnjp/nununu-20260621-450886/ ）。street（30×20 住宅街＋商店街）の差分リスト:

| 要素 | 夕方 | 深夜2:00 | 朝7:00 |
|---|---|---|---|
| tint | 茜（TOD_PRESETS） | 青暗 | 金 |
| 音 | ヒグラシ・17時チャイム・遠い電車・ドアベル | bgm null。足音・自販機のうなり・時折の風だけ | スズメ・カラス・シャッターを開ける音 |
| NPC | 6〜8体（雑談） | **0体** | 4〜5体（セリフ全差し替え） |
| 店 | 営業中。窓の灯り・のれん・店内の音 | 全店シャッター。コンビニ1軒だけ点灯 | 開店準備（のれん出し・水打ち・搬入） |
| 時計 | 商店街の時計など 17:XX（調べられる） | **全部 2:00** | 7:0X で動いている |
| 東端 | 工事囲い＋「工事のお知らせ」掲示 | **囲いが駅の入口に変わっている** | 囲いに戻る。作業員が準備中 |

- 実装コスト: tint は TOD_PRESETS 1行。NPC・看板文言は既存 when(tod) 分岐。店の開閉は灯りタイル数マスの差し替え＋シャッター表現で足りる。
  フルの生活スケジュールは不要（シェンムーの「朝出勤・昼食」程度の粗いルーチンでも生活感は出る https://www.famitsu.com/news/201403/20050226.html ）。
- 深夜のコンビニ1軒の灯りは style-spaces §1「暗闇の中の灯り」の日常版。中に入れなくてよい（灯りだけが生きている方が効く）。
- 時計は夕方から**調べられる小物**として3〜4箇所に置く（「気づけることの保証」＝ §3 の前提。8番のりばの実務知）。

## 3. 深夜への転換の一撃 — 強度の検証と推奨ビート

最初の違和感には A: 微差・否認可能型（P.T./8番出口）と B: 一撃・生活破壊型（夜廻の愛犬 https://www.4gamer.net/games/308/G030844/20151027035/ ）の2系統がある。
本作はジャンプスケア禁止・死なし・グロ無しの規範上 **A型一択**。現行プラン（無人・時計2:00・囲い=駅）は A型の教科書通りの階段であり妥当。推奨順序:

1. apart（深夜）: 違和感は1〜2箇所どまり（蛍光灯の明滅程度。DESIGN §4 のまま増やさない）
2. street 一歩目: 無人＋青暗＋静寂。これは「異変」でなく空気。脅威ゼロでも夜・無人・静寂というホラーの記号論だけで緊張は持つ（Gone Home、上掲）
3. 時計 2:00: 否認可能な微差。1個目は「止まってるのか」で流せてよく、2個目・3個目の**反復**で不気味の必然に変わる
   （P.T.: 反復＋微差が uncanny を生む https://killscreen.com/previously/articles/pt-turns-corner-horror/ ）。夕方に 17:XX を見せてあることが効きの前提
4. 囲い→駅の入口: 確定の一撃。東端＝視界の端に置く現行配置は「異変は角の先（視界の切れ目）に置く」の定石通り。
   **目撃のみ・実害なし・説明なし**で通す（RE7: 見せるが襲わせない https://www.thegamer.com/resident-evil-7-first-hour/ ）。駅名標は読める。それ以上は一切語らない

磨き込み案: 囲いの前に立った瞬間、遠くで終電の走行音を一度だけ小さく鳴らす（pan）。夕方に確立した定時音の反転であり
（SIREN: 共同体の定時音が怪異のスイッチになる https://corocoro-news.jp/news/125327/ ）、深夜2時の電車音は否認可能なまま「駅へ入る」動線誘導を兼ねる。
一撃の直後には必ず緩和を置く（build と release は両方要る https://www.gamedeveloper.com/design/the-balancing-act-of-tension-in-horror-game-design ）
——hub 入場直後のネムリンの寝ぼけがその役。プロローグでは死なせない・詰まらせない（失敗→リトライの反復は恐怖を最速で摩耗させる https://news.denfaminicogamer.jp/column05/horror ）。

## 4. 再訪の感情設計 — 朝の散歩を効かせる

順序が全て: ①夕方のルーティンで町と人を暗記させる（愛着の貯金）→ ②深夜に同じ町を失って見せる → ③朝に返す。愛着の貯金がないうちに違和感を出しても効かない。
場所への愛着は「そこで起きたことの記録」から生まれる（どうぶつの森 https://www.famitsu.com/news/202009/04205284.html ）ので、
朝は**夕方のプレイヤーの行動を覚えている**こと（ムジュラ: 介入の結果が残る/消える設計が感情の振れ幅を決める https://www.nintendo.co.jp/3ds/interview/ajrj/vol1/index7.html ）。対で実装する:

| 夕方の setup | 朝の payoff |
|---|---|
| コンビニ/商店で買い物・店主と一言 | 同じ店主が「昨日の」話題で挨拶。買った物が部屋の机に残っている |
| 下校の子ども2人の雑談 | 同じ2人が登校中。会話の続き（宿題まだやってない） |
| 犬の散歩の人（周回ルーチン） | 朝の散歩に再登場。犬が尻尾を振る |
| 17時チャイム・ヒグラシ | スズメと搬入の音に交代（チャイムは鳴らさない。定時音の要らない朝＝日常の回復） |
| 工事囲い＋お知らせ掲示 | 囲いが戻り作業員が準備中。掲示は昨日のまま |
| 街の時計 17:XX／room の時計 2:00 | 7:0X で動いている。room の秒針SEが戻る |
| 夜スレの賑わい（room）→深夜は止まっている | 朝、スレが動き出す（MGRoid らの一言。DESIGN §5） |

朝に新規タスクは置かない。歩いて確かめるだけの1〜2分。「昨日と同じだ」とキリコに言わせない（説明禁止・DESIGN §8）。
payoff のうち1個以上はプレイヤーの夕方の選択に依存させる（買った物・話しかけた相手で一言が変わる）。

## 5. 数値ノルマ（プロローグ）

- **全長（タイトル→hub 到達）12〜15分**。内訳目安: 夕方の町 5〜7分／夜の自室 2〜3分／深夜の町〜駅 3〜4分。
  根拠: 「完全無風」の実例上限は2〜3分（SH2 の霧の歩き・夜廻の犬の散歩）だが、伏線＋毎分1発見があれば30〜60分持つ（RE7/Amnesia）。
  分数でなく発見密度で管理し、最後はテストプレイで耳で合わせる（Bycer、上掲）。
- **調べ物**: street は16個以上（品質ノルマ12の上乗せ。3時間帯で使い回すため、うち8個以上に tod 差分の一言を持たせる）。room / apart は各ノルマ通り12個。
- **NPC**: 夕 6〜8体／深夜 **0体（必達。不在が最も安く強い時間表現）**／朝 4〜5体。モブは1〜2行、3層会話は店主1人（街路のガイド役）だけでよい。
- **伏線（不穏の種）**: 夕方に2〜3個。最初の1個は開始2〜3分以内。夕方時点で日常として読め、深夜以降に再文脈化されること。
- **深夜の違和感は3系統のみ**（無人／時計2:00の反復／囲い=駅）＋任意の微差1個まで（apart の蛍光灯）。
  足したくなったら間引く（Amnesia 実測: スケアの間隔を空けるほど怖くなった。Grip 上掲）。
- **深夜の道**: 東端まで実質一本道＋寄り道1本（IGA「探索型でも実はそんなに探索させない」 https://www.famitsu.com/news/201403/22050353.html ）。暗記済みの町なので再探索を強制しない。
- **朝**: 1〜2分・新規タスク0・payoff 5個以上。
